# Jared Lumley Technical Portfolio

Static GitHub Pages portfolio.

## Publish
1. Create a public repository named `jaredlumley.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Add `Jared_Lumley_Resume.pdf` to the repository root when your final résumé is ready.
5. Replace the placeholder LinkedIn/GitHub links in `contact.html`.

The project pages deliberately distinguish documented facts from proposed analysis so the portfolio does not make unsupported performance claims.
